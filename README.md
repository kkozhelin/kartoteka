# Картотека

Личная картотека заметок и списков дел. Две страницы Nuxt 4 SPA: полка и редактор. При первом открытии на полке появляются четыре примера, которые можно редактировать и удалять.

## Запуск в Docker

```sh
docker-compose up --build
```

Приложение доступно по адресу http://localhost:3000. В Compose v2 можно использовать команду `docker compose up --build`.

## Разработка

Нужен Node.js 24.11 или новее.

```sh
npm ci
npm run dev
npm run check
npm run build
npm start
```

`npm run check` проверяет типы и запускает Vitest. `npm start` запускает собранное приложение.

## Решения

- Pinia хранит состояние каталога в памяти. IndexedDB принимает записи только при сохранении и удалении. Транзакция проверяет ревизию заметки перед записью, поэтому устаревший редактор не перезапишет изменения другой вкладки и не восстановит удалённую заметку.
- Вкладки обмениваются сигналами об изменениях. При конфликте можно открыть актуальную версию или сохранить свой вариант новой карточкой.
- История редактора содержит до 50 обратимых операций. Ввод группируется до потери фокуса или паузы в 650 мс. Элементы управления редактора и клавиши Ctrl+Z / Ctrl+Shift+Z обращаются к истории заметки. В текстовом поле действуют нативные сочетания браузера. На macOS редактор поддерживает также Cmd.
- Черновик записывается в sessionStorage после паузы в 300 мс и при уходе страницы в фон. Он переживает перезагрузку в той же вкладке. История редактирования при перезагрузке начинается заново.
- Пустая заметка допустима, если у неё есть название. Пустое название или пункт из одних пробелов подсвечиваются при сохранении.
- Окна подтверждений используют нативный HTML-элемент dialog и поддерживают Escape, удержание фокуса и его возврат после закрытия.
